# Local interface fonts

The workspace bundles the Latin subsets of DM Serif Display (regular) and
Manrope (variable weights 400–700). Other scripts use the CSS fallback fonts.
No Google Fonts request is made by the running application. The existing
same-origin Content Security Policy remains unchanged.

Downloaded November 6, 2026 from Google Fonts:

- DM Serif Display: https://fonts.gstatic.com/s/dmserifdisplay/v17/-nFnOHM81r4j6k0gjAW3mujVU2B2G_Bx0g.woff2
- Manrope: https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggexSg.woff2
